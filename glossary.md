# Glossary

- Amortized inference: learning a model that predicts approximate posterior parameters directly.
- Bayesian inference: updating beliefs using likelihood and prior.
- Confounder: variable affecting both treatment and outcome.
- Contrastive learning: representation learning by comparing positive and negative pairs.
- EM: algorithm alternating hidden-variable inference and parameter updates.
- HMM: hidden Markov model with latent states and observed emissions.
- Latent variable: unobserved variable that helps explain observations.
- MCMC: sampling methods that use Markov chains to approximate a target distribution.
- MDP: Markov decision process for sequential decision-making.
- Posterior: distribution over unknowns after observing data.
- Prior: distribution over unknowns before observing data.
- State-space model: model with latent state evolving over time.
- Variational inference: approximate inference by optimization over a simpler distribution family.
- VAE: variational autoencoder, a neural latent variable generative model.
